# 관리자 통계 대시보드 완료 기준

작성일: 2026-07-09

## 목표

동아리 관리자 페이지에서 `/admin/statistics` 탭을 통해 내 동아리의 모집 성과를 확인할 수 있게 한다.

백엔드 API 명세는 저장소 루트의 `docs/spec/club-statistics-frontend-api-spec.md`를 기준으로 한다.

## 완료 기준

- `/admin/statistics`로 접근 가능하다.
- 데스크톱 사이드바와 모바일 설정 목록에 `통계` 메뉴가 노출된다.
- 기본 진입 시 KST 기준 최근 7일 통계를 자동 조회한다.
- 기간 변경 시 요약, 일자별 추이, 전체 주요 검색어 API가 같은 기간으로 갱신된다.
- 직접 선택 기간이 잘못되면 API 요청이 발생하지 않는다.
- 차트는 데이터 없음, 단일 날짜, 긴 기간에서도 레이아웃이 깨지지 않는다.
- API 하나만 실패해도 나머지 섹션은 표시된다.
- `PAGE_VIEW.ADMIN_STATISTICS_PAGE` 페이지뷰가 기존 tracking hook으로 기록된다.
- `npm run typecheck`가 통과한다.
- `npm run build`가 통과한다.

## 수동 QA 체크리스트

- `/admin` 모바일 설정 목록에서 `통계` 클릭 시 `/admin/statistics`로 이동한다.
- 데스크톱 사이드바에서 `통계` active 상태가 표시된다.
- 기본 진입 시 최근 7일 기간이 선택되어 있다.
- `최근 30일` 클릭 시 시작일과 종료일이 갱신되고 쿼리가 재실행된다.
- 직접 날짜 선택에서 시작일을 종료일보다 늦게 입력하면 에러가 뜨고 API가 호출되지 않는다.
- 데이터가 모두 0인 경우 빈 상태가 보인다.
- 검색어 데이터가 없는 경우 검색어 섹션만 빈 상태가 보인다.
- 긴 키워드는 한 줄 ellipsis 처리되고 count는 가려지지 않는다.
- 모바일 375px 폭에서 버튼, 날짜 input, 차트 라벨이 겹치지 않는다.
- 로그아웃 후 `/admin/statistics` 접근 시 로그인 페이지로 이동한다.

## 메모

- `search-keywords`는 전체 검색어 통계다. 내 동아리 유입 키워드처럼 표현하지 않는다.
- 평균 체류 시간은 초 단위 정수이며 UI에서 사람이 읽기 쉬운 단위로 변환한다.
- 서버 요청 파라미터는 API 계약에 맞춰 `from`, `to`를 사용한다.
- 차트 라이브러리 추가 후 번들 크기 영향이 커지면 차트 컴포넌트 lazy loading을 검토한다.
