# ⚠️ 절대 삭제 금지 — PR 이미지 보관 브랜치

이 브랜치는 PR 본문에 붙인 화면 캡처를 보관합니다.
**브랜치를 지우거나 파일을 옮기면 이미 머지된 PR 본문의 이미지가 모두 깨집니다.**

- 코드와 섞이지 않도록 다른 브랜치와 이력을 공유하지 않는 orphan 브랜치입니다.
- 머지 대상이 아닙니다. PR을 열지 마세요.
- 새 캡처는 추가만 하고, 기존 파일은 고치거나 지우지 않습니다.
